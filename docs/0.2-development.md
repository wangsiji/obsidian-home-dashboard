# 0.2 功能与验证说明

版本 0.2.0；发布状态以 GitHub Release 和官方目录为准。

- 搜索框输入内容后按 `⇧↵`，或点击「记一笔」，会追加到 Inbox 笔记；设置中可改为今日日记。成功后清空输入框，失败时保留原文。之前 `⇧↵` 的「在新标签打开搜索结果」行为已改为快速记录。
- 「常用」读取内置「书签」插件的文件和搜索书签，包含书签组内的项目；没有书签时不显示。
- 最近笔记、常用书签与每个插件模块都可以分别隐藏和设置显示条数，默认各 3 条。

快速记录默认写入库根目录的 `Inbox.md`，可在设置中改为其他库内 Markdown 路径。选择日记时必须启用内置「日记」插件。顶部「今日」按钮仍可打开日记，不再显示字数卡片。卡片只提供摘要和入口；任务与日程适配器留待后续版本。

## 页签与问题修复

在设置 → Qiaomu Home →「页签与模块」启用页签模式。原布局自动成为第一个页签；可新增、重命名、前后排序和删除页签，每页分别保存模块开关、1–6 条显示数量（默认 3 条）和推荐卡开关。新页为空，选择内容后显示；关闭页签模式显示第一张布局，再开启会恢复原页签。删除页签仅删除布局，不改笔记和插件数据。搜索仍覆盖全库与已接入插件，不受当前页的模块开关限制。

- 搜索下拉框：搜索区域整体位于页签和卡片之上，修复毛玻璃卡片遮挡搜索结果；照片模式使用不透明结果背景，避免下方文字透出。
- 插件连接：不再把接口暂不可用直接解释为“需要更新”。缺失接口提供打开插件与重试入口，不兼容接口单独说明；主页轻量观察插件实例和接口引用变化，延迟加载、启用/禁用和重载后自动刷新，关闭视图时清理定时器。
- 异步内容：切页立即清除上一页网格，迟到的插件/书签结果按渲染代次丢弃。

验证：30 项单元测试通过（含旧配置迁移、页签配置隔离/删除/排序与插件延迟注册）。隔离 Obsidian 桌面库验证了搜索重叠命中位置、通过设置创建与配置页签、键盘切换、重载持久化、暂时移除再恢复 Reader 接口后的自动重连，以及较慢结果不会跨页显示。尚无手机真机验证。

设计依据（2026-09-26）：[iTab 官方功能说明](https://www.itab.link/)中的分组管理作为交互参考；实现沿用本项目现有 Home 视图与模块配置，不复制第三方源码。[Obsidian 生命周期文档](https://docs.obsidian.md/plugins/guides/lifecycle-management)规定使用组件注册机制清理定时器与事件。
