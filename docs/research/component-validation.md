# Qiaomu Home 首批组件验收

日期：2026-09-27。代码版本：基于 `d9cbc12` 的工作区改动；测试宿主 Obsidian 1.13.7。该报告只证明隔离库中的本地运行结果，不代表插件市场已发布或移动端已验证。

## 首页适配结论

本轮交付 3 个模块，38 项是研究候选数。三个模块均默认关闭，用户从现有「添加内容」模块库启用，按页面保留显示、顺序和移除状态。卡片只显示 1–3 条可读内容与直接动作，所有笔记内容仍在原文件中；打开笔记使用新标签页，Home 留在原标签。今日日记与今日待办存在内容重叠，用户可按习惯选择其中一个。较高的默认「新手必装」卡片会把新增卡片推到首屏以下，后续可单独调整默认信息架构。
